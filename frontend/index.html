Meet the Sahayak AI Workforce

Unlike generic conversational chatbots that generate long text essays, Sahayak deploys task-oriented autonomous agents designed for structured public welfare execution.

Agent 1

Scheme Discovery Agent

Translates colloquial citizen needs into structured search vectors, queries Qdrant dense index, ranks 6–7 schemes, and flags top recommendations.

Agent 2

Eligibility Assessor Agent

Loads statutory scheme criteria from SQLite, compares against citizen demographic attributes, and flags verified criteria, exclusions, and items needing confirmation.

Agent 3

Document Readiness Agent

Audits required statutory documents against the citizen's demo locker, identifies missing files, and offers simulated OCR verification.

Agent 4

Application Drafter Agent

Synthesizes verified profile data into a reviewable, editable formal application package. Enforces mandatory citizen consent before simulation.

Agent 5

Lifecycle Tracker Agent

Generates simulated reference numbers, logs scrutiny events, updates dashboard metrics, and advises the citizen on their next best action.

Ethical & Safe AI

Citizen Control & Safety Principles

Designed for trust, transparency, and safety in last-mile government navigation.

Human-in-the-Loop Approval

No application is submitted automatically. The citizen retains complete control and must explicitly review and check the approval authorization.

Zero Identity Leaks

Sensitive identity proofs and Aadhaar numbers are never sent to external LLMs. Demonstrations use synthetic demo data only.

Deterministic Rule Engine

Eligibility is never left to LLM guesswork. Statutory age caps, land limits, and income exclusions are evaluated with deterministic application logic.

Safe Simulated Sandboxing

All submission endpoints execute strictly in simulated sandbox mode. Sahayak never attempts unauthorized live portal submissions.

Privacy, Safety & Citizen Consent

How Sahayak protects citizen rights, handles mock data, and enforces human-in-the-loop validation.

Human-in-the-Loop Consent

Every draft application produced by Agent 4 requires explicit citizen authorization before simulation. No agent can submit any application unilaterally.

No Sensitive Identity Uploads

Do not upload real Aadhaar cards or sensitive banking credentials. Sahayak provides pre-verified synthetic demo credentials for hackathon evaluation.

Simulated Registry Isolation

Application IDs (e.g. SHK-2025-XXXXX) and scrutiny timelines run in an isolated SQLite demo registry. No live government portal APIs are invoked.

Verified Statutory Rules

All scheme rules, benefit sums, and eligibility criteria are sourced directly from official portals (myScheme, India.gov.in) and audited with deterministic checks.
