Citizen Control Architecture

Empowering every Indian citizen to access their constitutional and statutory welfare rights.

Privacy, Safety & Citizen Consent

How JanSetu protects citizen rights, handles mock data, and enforces human-in-the-loop validation.

Human-in-the-Loop Consent

Every draft application produced by Agent 4 requires explicit citizen authorization before simulation. No agent can submit any application unilaterally.

No Sensitive Identity Uploads

Do not upload real Aadhaar cards or sensitive banking credentials. JanSetu provides pre-verified synthetic demo credentials for hackathon evaluation.

Simulated Registry Isolation

Application IDs (e.g. JS-2025-XXXXX) and scrutiny timelines run in an isolated SQLite demo registry. No live government portal APIs are invoked.

Verified Statutory Rules

All scheme rules, benefit sums, and eligibility criteria are sourced directly from official portals (myScheme, India.gov.in) and audited with deterministic checks.
